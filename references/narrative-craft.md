# narrative-craft · 旅行叙述写作指南

trip-design 的灵魂在叙述。脚本能保证数据可重复，但**让一份日记读起来像散文而非 AI 软文**只能靠写作纪律。

## 核心要求

| 维度 | 要求 |
|------|------|
| 视角 | **第一人称单数**（我）或复数（我们）。从语料推断，不强制 |
| 时态 | 中文不分时态；英文用过去时 |
| 长度 | 每日叙述 150-250 词中文（≈ 100-180 英文词）|
| 开头 | **必须感官细节开头**，不能用"今天/这一天我们..." |
| 结构 | 无固定结构——按当天的情绪节奏走，不强行分"早中晚" |
| 真实性 | 仅基于 EXIF + 视觉采样写。**不虚构**地点、活动、天气、用餐、人物 |

## 感官开头清单

视觉、听觉、触感、嗅觉、温度——任选一种切入：

| 类型 | 例 |
|------|-----|
| 视觉 | 「红墙在三月的阳光下泛着暖橙色，远处能看见海的轮廓。」 |
| 听觉 | 「水族馆穹顶下，巨大水槽的过滤声像风。」 |
| 触感 | 「珊瑚礁的边缘比想象中粗糙，沾水后才让脚趾打滑。」 |
| 温度 | 「下了缆车，山顶的风比山脚冷十度，外套还在车上。」 |
| 嗅觉 | 「旧那覇的小巷里，烤鸡皮的烟混着海风。」 |

**反例**（万金油 AI 公众号腔）：
- ❌「今天我们来到了美丽的冲绳」
- ❌「这一天充满了惊喜与感动」
- ❌「踏上了这片神奇的土地」
- ❌「难忘的回忆从这里开始」

## 多模态视觉采样位置

每天选 3 张照片做 Read（用 Claude Code 的多模态能力直接读图）：

| 位置 | 选哪张 | 用来获取什么 |
|------|--------|--------------|
| 首张 | 当天最早一张 | 早晨光线、出发地氛围 |
| 中张 | 时间排序中位 | 主要活动场景、当天高潮 |
| 末张 | 当天最晚一张 | 黄昏/夜晚氛围、收尾感 |

照片 ≤ 30 张时**全采样**，可以为每张写 caption（≤ 30 字）。

采样后**不要**直接复述图片内容（"图里有蓝色海面..."），而是把视觉信息**融入散文**：

- ❌ 直接复述：「这张照片里能看到一片蓝色的海，远处有几艘船。」
- ✅ 融入：「下午海面平得像玻璃，远处只有两三艘小船在颤动。」

## 不虚构边界

**允许**基于 EXIF + 地名 + 时间的合理推断：
- 「中午在国際通り附近」（地名 + 时间 + GPS 给的）
- 「下午沿海岸线开了 30 分钟」（多张连续 GPS 推断）
- 「这一站停了两小时」（首尾照片时间差）

**不允许**虚构具体内容：
- ❌「品尝了当地美食」（除非视觉采样里看见食物）
- ❌「与当地人聊了很久」（人物对话纯虚构）
- ❌「天气晴朗温暖」（温度 EXIF 没有；可写"光线明亮"如果照片显示）
- ❌「让人难以忘怀」（情感词不是观察）

视觉采样里看见才能写，看不见就留白。

## 笔墨分配

按地点的**停留时长**或**照片数**（代理）分配——拍得多/停得久的地方多写。

```
Day 2 · 美ら海水族館（22 张，停留 3.5 小时）+ 古宇利島（13 张，停留 4.5 小时）

笔墨 ≈ 60% 美ら海 + 40% 古宇利島
```

**反例**：每个地点平均一句——读起来像目录而非散文。

## 节奏与句长

中文叙述节奏感来自**长短句交错**：

```
水族馆的巨型水槽前，鲸鲨缓慢游过，光从水面折射下来，整面墙都在晃动。  ← 长
我屏住呼吸。                                                              ← 短
旁边的小孩没发出声音。                                                    ← 短
```

**反例**（排比堆砌）：
```
这里有热情的人们，这里有美丽的风景，这里有难忘的回忆，这里有...
```

## 旅行标题（trip_summary.title）

诗意命名，**不要**"我的 X 之旅" / "X 七日游" 这种白开水。

模板：「**地名 + 数字 + 意象**」或「**意象 + 短语**」

| 例 |
|---|
| 「冲绳七日，珊瑚礁与春风」 |
| 「东京冬夜，便利店的灯光」 |
| 「哲学之道，落樱与古书」 |
| 「青海三日，离星星更近」 |

不要用 emoji 装饰标题。

## 每日标题（days[].title）

≤ 10 字。一句话点睛当天最强烈的印象：

| 例 |
|---|
| 「青之洞窟」 |
| 「夕照古宇利」 |
| 「红墙之内」 |
| 「鲸鲨之下」 |

不要用「Day 1」「第一天」等数字标签当标题——day_number 已经在 hero 显示。

## Caption（可选，每张 ≤ 30 字）

仅在照片 ≤ 30 张时启用。caption 是**对图片内容的精确观察**，不是叙述：

| 例 |
|---|
| 「正殿屋顶的两条龙，金漆已斑驳。」 |
| 「下午三点的水槽，鲸鲨从左下方游入。」 |

caption 出现在 lightbox 底部，要能脱离上下文独立读懂。

## 反 slop 速查（重申 SKILL.md）

| 避免 | 采用 |
|------|------|
| 「今天我们...」开头 | 感官细节开头 |
| 「美丽 / 难忘 / 流连忘返」 | 具体名词 + 时间 + 触感 |
| 虚构活动 | 仅基于地名 + 时间合理推断 |
| 重复地名占字数 | 每段一个新角度 |
| 概括形容词「美食天堂」 | 视觉采样里的具体细节 |
| Emoji 装饰每段标题 | 标题独立成立 |
| 排比句堆砌 | 节奏变化，长短句交错 |
| 「踏上 / 邂逅 / 漫步」（旅游营销词）| 普通动词 |

每写完一段，**自检**：删掉所有形容词，剩下的名词和动词够不够撑起来？不够就是太空了。
