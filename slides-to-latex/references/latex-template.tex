\section{Example Topic}

\subsection*{Mean-Variance Choice}
The mean-variance framework compares portfolios through expected return and
variance. A risk-averse investor prefers higher expected return for a given
level of risk and lower variance for a given expected return.

\begin{equation}
  \sigma_p^2 = w^\top \Sigma w
\end{equation}

\begin{conceptbox}{Interpretation}
  The covariance matrix $\Sigma$ determines whether diversification reduces
  total portfolio variance.
\end{conceptbox}
