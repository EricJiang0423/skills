# art-direction · 艺术回忆策展指南

trip-design 的最终交付不是相册导出，而是一份艺术性的旅行回忆。GPS 和时间只提供骨架，真正的作品来自取舍、章节和文字。

## 目标

把一组照片变成“有表达的回忆”，不是“所有照片的网页列表”。

合格输出应该像：

- 一本小画册
- 一个旅行展览页
- 一段带图的私人 essay
- 一组按情绪和视觉线索组织的记忆

不合格输出通常像：

- Photos.app 网页导出
- 地点流水账
- hero + map + timeline + uniform grid 模板
- 每张照片都出现，但没有一张被真正看见

## 策展硬规则

### 1. 先删，再写

写 narrative 和 HTML 前必须先删照片。默认保留比例：

| 输入规模 | 建议最终入册 |
|---|---|
| 单日 50-300 张 | 8-18 张 |
| 单日 300+ 张 | 12-24 张 |
| 多日 500-3000 张 | 20-60 张 |
| 多日 3000+ 张 | 30-80 张，按章节分配 |

用户明确要“相册归档”时才放宽；否则不要以覆盖率为目标。

### 2. 直接删除的照片

除非用户明确要求或它们承担清楚叙事，否则删除：

- 睡觉、闭眼、疲惫丑照
- 脚、腿、手、手指遮挡、误触
- 票据、二维码、排队号、菜单截图、证件、屏幕拍摄
- 模糊、过曝、欠曝、构图失败
- 同时间同地点的重复自拍
- 纯转场且没有视觉信息的车厢/机场/酒店图
- 只证明“到过这里”但画面没有审美价值的打卡图

可以保留的例外：这些照片本身就是故事关键。例如“凌晨机场崩溃感”“雨中遗失车票”“脚上泥水是徒步证据”。保留时必须在 caption 里说明叙事价值。

### 3. 强图判断

一张照片值得入册，至少满足以下一项：

- 光线强：蓝 hour、斜阳、室内光、阴影有形状
- 构图强：框景、纵深、对称、尺度关系清楚
- 地点强：一眼看出城市/建筑/自然特征
- 人物强：人和环境有关系，不是孤立自拍
- 细节强：食物、票、物件、墙面、花、窗等能承载记忆
- 转折强：从一个章节进入另一个章节

如果只能写出“某地的一张照片”，它不够强。

## 组织结构

### 地点不是默认结构

地点聚类只作辅助索引。出现以下情况时，必须降级为视觉章节：

- GPS fallback 或 SQLite 直读导致地点标签粗糙
- 同一天地点过碎，读起来像流水账
- 城市内部移动距离短，但视觉差异大
- 用户想要“艺术性的旅行回忆”，不是行程记录

视觉章节示例：

- 「米兰的石面」
- 「水巷与转角」
- 「佛罗伦萨的室内光」
- 「斜塔之外」
- 「罗马的重力」
- 「运河、春花、蓝色黄昏」

### 章节分配

每个章节建议：

- 1 张主图：承担情绪和第一印象
- 2-6 张 stills：补充细节、人物、局部或转折
- 1 段 100-220 字叙述：回应主图和 stills
- 每张图 1 句 caption：必须是具体观察，不是泛泛赞美

## 文字规则

### Narrative 必须回应画面

不要只写路线：

> 上午去了 A，下午去了 B，晚上去了 C。

改成写画面之间的关系：

> 砖拱门把运河框成一幅窄画，水面、绿树和桥下的阴影先把这一天放慢。

### Caption 是入场券

每张入册照片都应有 caption。写不出 caption，通常说明这张照片不该入册。

Caption 不写：

- “美丽的风景”
- “开心合影”
- “著名景点”

Caption 要写：

- “砖拱门把运河框住，整天最安静的一张。”
- “蓝夜里的斗兽场和白裙，最后的记忆变得戏剧化。”
- “米兰大教堂前的灰白广场，人被尖塔压成小小的尺度。”

## HTML 结构规则

默认不要使用“所有地点块 + 均匀照片 grid”。这种结构很容易变成相册导出。

优先使用：

- 主图 + 长段文字 + 侧栏 stills
- 章节式画册
- 横向 film strip
- 大留白单图
- 图文错位排版
- 地图作为小索引，而不是首屏主角

地图可以出现，但只回答“这条记忆大致在哪里”。它不应该决定页面结构。

## 最终自检

交付前逐项检查：

- [ ] 是否删除了睡觉、脚、票据、二维码、证件、手指遮挡、重复图？
- [ ] 每张入册照片是否能说清“为什么值得出现”？
- [ ] 是否每张入册照片都有具体 caption？
- [ ] 叙述是否回应了照片中的光线、构图、人物、物件或空间？
- [ ] 地点聚类是否只是辅助，而不是强行主导叙事？
- [ ] 页面是否不是普通照片 grid？
- [ ] 设计方向是否和上一份明显不同？
- [ ] 最终作品读起来像旅行回忆，而不是相册导出？
